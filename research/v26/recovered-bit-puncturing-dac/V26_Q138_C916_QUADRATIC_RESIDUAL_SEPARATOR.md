# V26 q=138 C916 quadratic separator residuals

## Status

Exact edge-by-edge GF(2) function-space certificate for the best C same-support grouped-e0 quadratic-function separator tree. This refines the width-70 certificate by separating ordinary affine shared information from genuinely quadratic residual information.

This is **not** yet an exact nonlinear message-count or complete-C2 certificate. `ALPHA_PASS=0`.

## Construction

For each non-root edge with factor subset `S`, let

`J = F_S ∩ F_Sbar`,

where `F_S` is the span of the aggregate linear signature functions together with aggregate right-only scalar quadratics. The probe computes `J` exactly, then intersects it with the affine function space generated by the constant plus the 149 shared linear coordinates.

The quadratic projection kernel is exactly the affine subspace, hence

`quadratic_residual_dim = dim(J) - dim(J ∩ Affine)`

is exact for these degree<=2 function spaces.

## Interpretation

The width-147 result from forcing all aggregate scalar information into linear refinements of the original shared-state bits is therefore highly pessimistic. On the exact quadratic-function tree, the nonlinear shared part never exceeds 13 function dimensions.

This does **not** imply a `2^13` nonlinear message count automatically. Evaluation tuples of quadratic functions can have additional compatibility constraints, and conditioning on affine separator values changes the restricted quadratic Gauss classes. The next valid step is cut-restricted evaluation-image / character analysis using the exact quadratic Gauss primitive.
