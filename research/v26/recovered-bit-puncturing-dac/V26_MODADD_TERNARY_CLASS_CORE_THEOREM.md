# V26 Modular-Addition Ternary-Class Core Theorem

## Purpose

`V26_MODADD_LOCAL_TT_RANK_THEOREM.md` proved by exact rational rank calculation that one interior modular-addition Walsh bit tensor has optimal TT profile `[2,3,3,2]`.

This note identifies what the rank-3 auxiliary states **mean**. They are not arbitrary SVD modes: they can be chosen as the three equality classes of a binary pair

`00`, `11`, `unequal`.

This gives an explicit exact three-core factorization of the five-leg tensor and explains the fixed-leg rank reductions algebraically.

## 1. Local Walsh tensor

For one interior addition bit,

`T(s,t,u,v,w)`

`= 1[t = s xor u xor v xor w]`

`  * 1[s=1 or (u=v=w)]`

`  * (-1)^((u xor w)(v xor w))`

`  * 2^{-s}`.

Here `s` is the current sigma/carry state and `t` is the next state in the downward recurrence.

## 2. Ternary equality class

Define

`class(x,y) = 0` if `(x,y)=(0,0)`,

`class(x,y) = 1` if `(x,y)=(1,1)`,

`class(x,y) = 2` if `x != y`.

Let

`c = class(u,t)`

and

`d = class(v,w)`.

Both `c` and `d` take exactly three possible values.

## 3. Left class tensor

Define

`A(u,t,c)`

`= 1[c = class(u,t)] * 2^{-1[u != t]}`.

Thus

- `(u,t)=00` maps to `c=0` with weight `1`;
- `(u,t)=11` maps to `c=1` with weight `1`;
- `(u,t)=01` or `10` maps to `c=2` with weight `1/2`.

This is an exact rank-3 map from the pair `(u,t)` to the ternary class state.

## 4. Right class tensor

Define

`B(d,v,w)`

`= 1[d = class(v,w)] * (-1)^{v(1-w)}`.

Therefore

- `00 -> d=0` with sign `+1`;
- `11 -> d=1` with sign `+1`;
- `01 -> d=2` with sign `+1`;
- `10 -> d=2` with sign `-1`.

The unequal class retains the orientation-dependent Walsh sign without requiring a fourth class state.

## 5. Middle sigma tensor

Define `H(c,s,d)` by the following nonzero entries.

For `s=0`:

- `H(0,0,0)=1`;
- `H(1,0,1)=1`.

For `s=1`:

- `H(0,1,2)=-1/2`;
- `H(1,1,2)=+1/2`;
- `H(2,1,0)=1`;
- `H(2,1,1)=1`.

All other entries are zero.

## 6. Exact factorization theorem

For every binary tuple `(s,t,u,v,w)`,

`T(s,t,u,v,w)`

`= sum_{c=0}^2 sum_{d=0}^2 A(u,t,c) H(c,s,d) B(d,v,w)`.

This identity was checked exhaustively on all `2^5=32` entries using exact rational arithmetic. It also follows directly from the two sigma cases below.

### Case `s=0`

The nonzero condition forces

`u=v=w`

and the recurrence gives

`t=u`.

Hence both pairs `(u,t)` and `(v,w)` are equal and have the same value:

- all zeros gives `(c,d)=(0,0)`;
- all ones gives `(c,d)=(1,1)`.

Those are exactly the two nonzero `s=0` entries of `H`.

### Case `s=1`

The equality restriction disappears, while the recurrence becomes

`u xor t xor v xor w = 1`.

Equivalently,

`(u xor t) xor (v xor w) = 1`.

Therefore exactly one of the two pairs `(u,t)` and `(v,w)` is unequal.

So either

- `c=2` and `d in {0,1}`, or
- `c in {0,1}` and `d=2`.

Those are exactly the four `s=1` transitions of `H`.

The factors `A`, `H`, and `B` reproduce the magnitude `1/2` and the orientation-dependent Walsh sign in every case.

## 7. Why the TT rank is exactly 3

The factorization gives an explicit ternary bond on both sides of the central sigma core, so the pair-grouped network has bond dimensions at most

`3 -- H(s) -- 3`.

The exact rank table from `V26_MODADD_LOCAL_TT_RANK_THEOREM.md` shows that every 2|3 flattening avoiding current sigma `s` has rank exactly 3.

Therefore these ternary class bonds are not merely sufficient; their dimension is minimal for the corresponding pair cuts.

This gives a semantic explanation of the optimal `[2,3,3,2]` five-leg TT profile.

## 8. Fixed-leg reductions

The class picture immediately explains the lower ranks used in the fixed-IO QR network.

### Fixed `u`

If `u` is fixed, then as `t` varies the class `class(u,t)` can take only two values:

- the matching equal class (`00` or `11`),
- `unequal`.

So the left ternary bond reduces to dimension at most 2.

This is the structural reason `T1/T2` fixed-`u` tensors admit the reduced `[2,3,2]` profiles.

### Fixed `w`

If `w` is fixed, then as `v` varies `class(v,w)` also takes only two values.

So the right ternary bond reduces to dimension at most 2.

This explains the corresponding `T4` fixed-`w` reduction.

### Fixed `s=0`

For `s=0`, the middle tensor keeps only

`c=d=0`

or

`c=d=1`.

The unequal state disappears entirely. Thus the active central class space has dimension 2, matching the strong MSB endpoint reductions seen in the fixed-IO QR factorization.

## 9. Significance for FDS

The local Walsh tensor has two simultaneous exact state descriptions:

1. a binary longitudinal sigma/carry state along bit position;
2. a ternary transverse equality-class state across local mask-pair cuts.

The enormous explicit trail support is therefore generated by a network whose meaningful hidden states are only

- carry/no-carry style binary sectors, and
- `00 / 11 / unequal` ternary sectors.

This is a stronger structural statement than merely observing a low numerical tensor rank.

It suggests that future separator compression should preserve and exploit these sectors explicitly instead of treating bond-3 indices as anonymous dense coordinates.

## 10. Global-width caveat

Grouping `(u,t)` and `(v,w)` into semantic three-core factors is algebraically exact, but fewer local tensor vertices do **not** automatically imply a smaller global contraction width.

An exploratory 32-bit fixed-IO QR construction using the semantic three-core grouping reduced the local graph from 568 minimal single-leg TT cores to 411 tensors, but a finite balanced-cut search did not improve the existing certified `W <= 41` global bound.

This exploratory graph search is not a NO-GO and is not admitted as an optimality result. Its role is only to separate two notions:

- local semantic compression;
- global contraction geometry.

The local theorem remains exact regardless of that global search outcome.
