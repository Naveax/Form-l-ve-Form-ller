# V25 Exact Modular Half-Key Separability

Fresh Issue #11 protocol completed without retuning.

No fresh target had an exact modular-additive width even at **m=4**. Therefore the frozen common-width >=8 primary gate fails immediately.

Zero rectangle-residual fractions were only about 6.9% at m4 and 1.16% at m8; m4 exercised all 16 residual values and m8 all 256 values. This is not an almost-exact low-bit law.

With selected exact width 0, the half match set remains all **65,536** pairs on every target.

Decision: `NO_GO_SIMPLE_MODULAR_8P8_SEPARABILITY`. Synthetic exact-modular math tests 2/2 PASS. No MITM scaling stage; alpha remains unproven.
